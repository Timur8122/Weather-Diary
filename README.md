# Weather Diary

## Описание проекта
"Weather Diary" — это простое графическое приложение для ведения дневника погоды. Оно позволяет добавлять записи о погоде, смотреть их, фильтровать по дате и температуре, а также сохранять и загружать данные из файла JSON. Всё это реализовано с помощью Python и библиотеки tkinter.

## Основные возможности
- Ввод и добавление новых записей о погоде:
  - Дата (разрешены форматы: ГГГГ-ММ-ДД)
  - Температура (число)
  - Описание погоды (строка)
  - Наличие осадков (да/нет)
- Просмотр всех добавленных записей в таблице.
- Сохранение данных в файл `data.json` и их загрузка.
- Простая фильтрация данных по критериям (например, по дате или диапазону температур).
